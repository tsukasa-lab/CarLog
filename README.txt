CarLog Ver.0.11

PWA対応版です。
GitHub PagesなどHTTPS環境へ、このフォルダ内のファイルをすべて配置してください。

公開後:
Android/Chrome: メニュー → ホーム画面に追加 / アプリをインストール
iPhone/Safari: 共有 → ホーム画面に追加

注意:
index.htmlをPCで直接ダブルクリック(file://)した場合、通常のCarLog機能は使えますが、
Service WorkerによるPWA/オフライン機能は有効になりません。

Ver.0.9:
- スマホ下部に固定ナビゲーションを追加
- 中央の＋ボタンから「給油」「整備・修理」「その他支出」をすぐ選択可能
- 既存データ形式・バックアップ形式は維持

Ver.0.10:
- PWA更新処理を改善
- Service Workerを毎回更新確認し、新版有効化時に自動再読み込み
- アプリ本体はオンライン時Network-first、オフライン時キャッシュ利用
- PC表示時の下部ナビ横幅崩れを修正
- localStorageの車両・給油・整備・支出データはそのまま維持

Ver.0.11:
- ＋メニューの「給油」「整備・修理」「その他支出」が反応しない問題を修正
- 実際の入力画面関数へ直接接続
- 車両未登録時は下部ナビを非表示
- PWAキャッシュをv0.11へ更新
