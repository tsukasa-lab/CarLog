CarLog Ver.0.9

PWA対応版です。
GitHub PagesなどHTTPS環境へ、このフォルダ内のファイルをすべて配置してください。

公開後:
Android/Chrome: メニュー → ホーム画面に追加 / アプリをインストール
iPhone/Safari: 共有 → ホーム画面に追加

注意:
index.htmlをPCで直接ダブルクリック(file://)した場合、通常のCarLog機能は使えますが、
Service WorkerによるPWA/オフライン機能は有効になりません。
